# PALM CLUB Discord コミュニティ活性化戦略

## コミュニティの目的・ターゲット

| ターゲット | ニーズ |
|-----------|--------|
| タイ移住に興味がある人 | 情報・経験談・現地のつながり |
| ノマドになりたい人 | 仕事のやり方・マインド・仲間 |
| やりたいことはあるが動けない人 | 背中を押す環境・習慣化 |
| タイで収入の柱を作りたい人 | ビジネス・マーケティング知識 |
| 人脈を作りたい人 | 交流・コラボ機会 |
| MASAのファン | MASA直接の発信・Q&A |

---

## 1. 毎日の「儀式」設計（Daily Rituals）

毎日同じ時間に同じアクションが起きると、メンバーが「今日も開こう」と思う習慣が生まれる。

### 朝ルーティン（7:00〜9:00 JST）
| チャンネル | アクション | 担当 |
|-----------|-----------|------|
| `#今日の一言` | MASA or モデレーターが今日のテーマ一言を投稿 → メンバーが返信 | MASA/Bot |
| `#今日やる事1日の積み上げ` | 「今日の3つのToDoを書こう」テンプレ投稿 | Bot |
| `#今日走った距離報告` | ランクラブ向け「今朝走った？」声かけ | モデレーター |

### 夜ルーティン（21:00〜23:00 JST）
| チャンネル | アクション | 担当 |
|-----------|-----------|------|
| `#今日やった事` | 「今日の成果を報告しよう！」テンプレ投稿 | Bot |
| `#今日の一言` | 今日一番良かった発言にMASAがスタンプ反応 | MASA |
| `#雑談ルーム` | 「今日の雑談タイム」音声部屋への誘導コメント | モデレーター |

## 2. ウィークリーイベント設計（Weekly Events）

| 曜日 | イベント名 | 内容 | チャンネル |
|------|-----------|------|-----------|

| 日曜 | **週まとめ＆ベスト投稿紹介** | モデレーターが週の名投稿をまとめて紹介 | `#大事なお知らせ` |

## 3. 参加型コンテンツ（Engagement Hooks）

### A. 「挑戦」系コンテンツ
```
例）「今週のチャレンジ：タイ語を1フレーズ覚えて投稿してみよう」
→ メンバーが #雑談ルーム に投稿 → MASAがリアクション
```

### B. 「質問」型投稿（モデレーターが定期投稿）
```
月曜：「今週一番やりたいことは何？」
水曜：「タイに移住するとしたら一番不安なことは？」
金曜：「今週学んだことを1行で教えて！」
```

### C. 「紹介してもらえる」仕掛け
- `#snsの自己紹介` チャンネルで投稿した人をモデレーターがX（Twitter）でシェア
- 「PALM CLUBメンバー紹介」としてMASAのpodcastや発信で名前を出す
- 週に1人「今週のMVPメンバー」を選んでアナウンス

## 4. 無料招待の拡散モデル（Viral Growth）

### メンバーが人を連れてくる仕組み

**招待リンクの整備**
- 期限なしの固定招待リンクを1本作成
- 招待リンクをコピーしやすい形で `#はじめに読んでね` に固定

**紹介インセンティブ（無料でできるもの）**
| 紹介人数 | 特典 |
|---------|------|
| 1人招待 | `#自己紹介` でモデレーターに特別スタンプをもらえる |
| 3人招待 | MASAがX（Twitter）でメンションして紹介 |
| 5人招待 | MASA直接Q&Aに優先参加権（月1回） |
| 10人招待 | `INSIDE-限定` チャンネルへのアクセス権 |

**招待を促すテンプレートメッセージ（メンバーに配布）**
```
タイ移住・ノマド・海外ビジネスに興味ある人いたら
無料のDiscordコミュニティ「PALM CLUB」に入ってみて！

MASAさんが運営してて、毎日盛り上がってるよ。
無料招待リンク：[LINK]
```

## 5. チャンネル別活性化アクション

### `#自己紹介`
- 投稿フォーマットを固定して書きやすくする
```
【自己紹介テンプレ】
名前（ニックネームOK）：
どこに住んでる？：
タイ/ノマドに興味を持ったきっかけ：
コミュニティに期待すること：
趣味・特技：
```
- 新規メンバーが投稿したら、モデレーターが必ず24時間以内に返信

### `#今日の一言`
- MASAが毎朝1投稿（ショートで良い）
- モデレーターが「今日のテーマ」を投稿して返信を促す
- 例：「今日のテーマ：最近一番ワクワクしてることを一言で」

### `#質問してokルーム`
- 質問に48時間以内に必ず誰かが返信するルールを設ける
- モデレーターが未回答の質問をチェック
- 良い質問と回答は `#学びの質問ルーム` にまとめて転載

### `#タイの事何でも雑談ルーム`
- モデレーターが週2回「タイあるある」「タイ豆知識」を投稿して話題提供
- バンコク現地メンバー（PALM HOUSE BKKメンバー）がリアルタイム情報を発信する仕組み

### `ラジオスペース`（音声）
- 毎週金曜夜に「フリートークタイム」を開催
- 参加バリアを下げる：「話さなくても聞くだけでOK」を告知

## 6. モデレーター行動マニュアル

### 毎日やること（15分）
- [ ] 各チャンネルの最新投稿を確認
- [ ] 未返信の自己紹介・質問に返信
- [ ] 今日の一言チャンネルにコメント or リアクション
- [ ] 積み上げ系チャンネルを確認してスタンプで反応

### 週次でやること（30分）
- [ ] 週のMVP投稿をまとめて `#大事なお知らせ` に投稿
- [ ] イベント告知の投稿スケジュール確認
- [ ] 非アクティブメンバーへのウェルカムDM（参加後2週間無発言の人）

### ウェルカムDMテンプレ（新規メンバー向け）
```
PALM CLUBへようこそ！

まずは #自己紹介 チャンネルで自己紹介してみてください。
テンプレがあるので書きやすいと思います！

毎日 #今日の一言 と #今日やる事1日の積み上げ が
コミュニティの習慣スポットになってます。

気軽に参加してね！
```

## 7. Botで自動化できること

Discord Bot（Carl-bot / MEE6 / Botや自作Bot）を使って以下を自動化：

| 機能 | 内容 |
|------|------|
| ウェルカムメッセージ | 新規参加者に自動DM送信 |
| 定期投稿 | 毎朝・毎晩の「積み上げ」テンプレを自動投稿 |
| レベルシステム | 投稿数に応じてロール付与（アクティブメンバー表示） |
| 招待数カウント | 誰が何人招待したか自動集計 |
| リマインダー | イベント前日・当日に自動告知 |

## まとめ：活性化の3大原則

1. **毎日の小さな習慣をつくる**
   → 積み上げ・一言・走った距離…継続しやすい小さなアクション

2. **MASAが反応する = メンバーが嬉しくなる**
   → スタンプ1つでもいい。MASAが見てると思えると投稿したくなる

3. **参加することで得をする設計**
   → 紹介すると特典、発信するとXでシェア、質問すると答えてもらえる
