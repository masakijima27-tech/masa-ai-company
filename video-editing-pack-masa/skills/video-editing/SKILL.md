# video-editing — カット＆テロップ全自動パイプライン

動画ファイルを受け取ったら、このスキルの手順で編集を完了させる。
実作業はすべて `scripts/pipeline.py` に任せる。個別スクリプトを手で順番に呼ばない
（工程飛ばし・順序ミス・品質チェック漏れを防ぐため）。

## 手順

### 1. 素材確認

```bash
ls -la "<動画パス>"
```

存在しなければユーザーにパスを確認する。

### 2. ユーザーに聞くこと（1回だけ・2問）

**Q1 仕上がりの形は？**
- [1] 縦リール（Instagram / TikTok・1080x1920・白テロップ）← 迷ったらこれ
- [2] 横講座（YouTube・1920x1080・黄テロップ・画面下部）

**Q2 出力は？**
- [a] 完成MP4だけ（既定）
- [b] MP4 + SRT字幕ファイル
- [c] MP4 + SRT + FCPXML（Final Cut Proで続きを編集する人向け）

カットの細かい指定（冒頭カット・無音の長さ・消したい範囲）は聞かれなくてよい。
ユーザーが自分から指定したときだけ、下記オプションで反映する。

### 3. 実行

```bash
cd <このスキルのscripts/>
python3 pipeline.py --new "<動画パス>" \
  --route vertical \        # vertical | horizontal
  --outputs mp4,srt \       # mp4 / srt / fcpxml をカンマ区切り
  --out-dir "<動画と同じフォルダ>"
```

任意オプション:
- `--silence 0.7` 無音とみなす秒数（既定1.0。テンポ重視なら0.7）
- `--head 3 --tail 2` 冒頭・末尾を無条件カット
- `--filler off|standard|strong` フィラー（えー、えっと）除去の強さ
- `--vocab <path>` 語彙辞書（省略時は assets/vocabulary.json を自動使用）

工程は probe → transcribe → jetcut → master → captions → render → qc → export の順で自動実行される。
途中で失敗しても、同じコマンドを再実行すれば済んだ工程はスキップされて続きから走る。

### 4. テロップ推敲（必須・あなたの仕事）

パイプライン完走後、`<work>/captions.json` を必ず読んで推敲し、`--force render` で焼き直す。
機械処理（BudouX）は文節までしか判定できないので、最後の仕上げはあなたの言語能力で行う：

- **ひらがな連続を漢字に**（例: うさんくさい → 胡散臭い）。読みやすさが大きく変わる
- **聞き間違いの文脈復元**（例: シーって言うなら → 強いて言うなら／やってるさって → やってる、差って）。前後の意味から明らかな場合のみ
- **語尾の演出**: 決め台詞に「！」を足す程度はOK
- **守ること**: 話者の言葉を言い換えない（意味の改変禁止）・1行は max_chars+4 文字まで・最大2行・
  時刻(s/e)は隣接画面と重ならない範囲でのみ調整可

**リズムの基準（お手本）**: 目指すのは「1画面1呼吸」。1画面に2フレーズ詰めず、画面を割って畳みかける。

| 機械生成のまま（NG例） | 推敲後（OK例） |
|---|---|
| 隠すの辞めます／僕が今バンコクで | 隠すの／辞めます！ → 僕が今／バンコクで |
| でね、ここで／大事なこと言います | でね、ここで → 大事なこと言います！ |
| 最後まで見てくれた人／本当ごめんなさい | 最後まで／見てくれた人 → 本当ごめんなさい！ |
| 稼いでる人イコール | 稼いでいる人／＝ |
| 秘密なかったです | 秘密、／なかったです |

- 意味の区切りごとに画面を割る（画面数が増えるのは歓迎。1画面1〜2秒でテンポが出る）
- 上の行を短くしてタメを作る（ちょっと／胡散臭いんだけど）
- 「、」で溜め、決めに「！」、イコール等は記号（＝）にできる
- 「ご視聴ありがとうございます」系の締めの定型あいさつは基本カット（残す指示があれば残す）

推敲したら:
```bash
python3 pipeline.py --job <work>/job.json --force render
```
（--force captions にすると推敲が消えて機械生成に戻るので注意）

### 5. 品質改札（qc）がNGで止まったら

`<work>/qc_report.json` を読み、NG項目に応じて直す:

- テロップ整合NG → `<work>/captions.json` を直接修正（誤変換・行割り）→ `--force render` で再実行
- 尺・解像度NG → job.json の設定を確認 → `--force jetcut` で再実行
- ラウドネスNG → `--force master`

修正して再実行し、全通過するまで出荷しない。

### 6. 完了報告

1. `<work>/qc_frames/` のPNGを2〜3枚ユーザーに見せる（テロップの見た目確認）
2. カット結果を報告する（例: 「92秒 → 71秒。無音18秒とフィラー6箇所を削除しました」。数値は cut_plan.json から）
3. 納品ファイルの場所を伝える

### テロップの見た目を変えたいと言われたら

job.json の `telop` を編集して `--force render`:

```json
"telop": {
  "color": "#FFDC32",     // 文字色
  "y_ratio": 0.80,        // 縦位置（0.5=中央、大きいほど下）
  "font_ratio": 0.06,     // 文字サイズ（画面幅比）
  "max_chars": 10,        // 1行の最大文字数（縦リール既定10 / 横講座16）
  "max_lines": 2,         // 1画面の最大行数（2段テロップ）
  "lead_s": 0.2           // テロップを声より先行表示する秒数（遅く感じたら増やす）
}
```

### 誤変換を直したいと言われたら

その場しのぎなら captions.json を直接修正。
毎回出る誤変換なら assets/vocabulary.json に登録する（次回から自動補正）。
登録方法は assets/vocabulary.example.json を参照。

## 初回セットアップ（環境が整っていない人）

```bash
python3 scripts/doctor.py                      # 何が足りないか表示
python3 scripts/doctor.py --download-model     # whisperモデル取得（高精度）
python3 scripts/doctor.py --download-model small  # 軽量版（古いPC向け）
```

doctor のNG項目に表示されるヒント通りに導入すれば揃う。
