# face-stamp — 顔にスタンプを自動追従させる

顔出ししない人の動画に、キャラクターのスタンプを顔の上に乗せ続ける。
DMM亀山会長のYouTubeと同じ見せ方（顔だけイラストで隠す、それ以外はそのまま）。

実作業は `scripts/facestamp.py` に任せる。ffmpegコマンドを自分で組み立てて代替しない。

## 前提

- 初回だけ `bash scripts/setup_env.sh` を実行する（このスキル専用の Python 環境を作る）
- 以降は `.venv/bin/python` で呼ぶ。システムの `python3` では動かない
- スタンプは**透過PNG**（背景が抜けている画像）。無ければ `assets/sample_stamp.png` で位置合わせだけ先に確認する

## 手順

### 0. スタンプ画像の下ごしらえ（背景が透過されていないとき）

もらったイラストが白背景・生成り背景のままなら、先にこれを通す。
背景を残したまま合成すると、四角い板が顔に貼りついたようになる。

```bash
.venv/bin/python scripts/prep_stamp.py "<もらった画像>" assets/<名前>.png \
  --check /tmp/stamp_check.png
```

- 四隅から繋がっている色だけを抜くので、顔の肌色や白いハイライトは消えない
- `--check` で出る市松模様の画像を**必ず開いて見る**。抜けすぎ・残りすぎがないか確認する
- 背景が抜けない → `--tol` を上げる（20 → 35）／絵の一部まで抜ける → `--tol` を下げる
- 同時に「絵の中のどこが顔か」を測って `<名前>.json` に保存する。
  帽子のつばのように顔以外が張り出した絵でも、これで横ズレしなくなる

### 1. ユーザーに聞くこと（1回だけ・2問）

**Q1 スタンプ画像は？**
- [1] 用意がある → パスをもらう（透過されていなければ手順0を通す）
- [2] masaさんの動画 → `assets/masa_stamp.png`（調整済み。大きさの指定も不要）
- [3] まだ無い → `assets/sample_stamp.png`（仮）で試して、本番用は別途作る

**Q2 大きさは？**（調整済みスタンプを使うときは聞かなくていい）
- [1] 顔だけ隠れればいい（`--scale 1.8`）
- [2] 頭ごと大きめに隠す（`--scale 2.4`）← 迷ったらこれ

### 2. まず10秒だけ試す（必ずこの順番）

いきなり全編を書き出さない。位置と大きさは1回で決まらない。

```bash
cd <このスキルのフォルダ>
.venv/bin/python scripts/facestamp.py \
  --video "<動画パス>" \
  --stamp "<スタンプPNG>" \
  --preview 10 \
  --out /tmp/facestamp_preview.mp4 \
  --sheet /tmp/facestamp_preview.jpg
```

`--sheet` で出た確認用の画像を **必ず自分で開いて見る**。顔が出ていたら数値を直してやり直す。

| 症状 | 直し方 |
|---|---|
| スタンプが小さくて顔がはみ出る | `--scale` を上げる（2.4 → 3.0） |
| 口や顎が出る（デフォルメの絵は顔が短い） | `--offset-y 0.15`（プラスで下へ）＋`--scale`も上げる |
| おでこ・髪が隠れない | `--offset-y -0.25`（マイナスで上へ） |
| 左右にずれる | 手順0を通していない可能性。通しても残るなら `--offset-x 0.05` |
| 顔が検出されない（検出率が低い） | `--score 0.4` に下げる。それでも駄目なら `--detector haar` |
| カクカク動く | `--smooth 0.1`（小さいほど滑らか）／`--every 1`（毎フレーム検出） |
| 顔が映っていないカットにスタンプが居座る | `--lost-hold 1.0`（1秒で消える） |
| 画面の端でスタンプが切れる | 既定の `--edge clamp` が効いている。切れてよければ `--edge free` |

### 3. OKが出たら全編を書き出す

`--preview` を外して同じオプションで流す。

```bash
.venv/bin/python scripts/facestamp.py \
  --video "<動画パス>" --stamp "<スタンプPNG>" \
  --out "<元の名前>_stamped.mp4" --sheet "<元の名前>_check.jpg"
```

数値を振って良い組み合わせが決まったら、次回から指定しなくて済むように
スタンプの `<名前>.json` に書いておく（`--scale` 等を省略したときに使われる）。

```json
{"face": {...}, "recommend": {"scale": 2.4, "offset_y": 0.15}}
```

### 4. 完了報告の前に必ず確認する（あなたの仕事）

出力後のレポートを読み、**顔の検出率**と**はみ出し**を報告に含める。

- はみ出しが 0 でないときは、`--scale` を上げて焼き直す
- 検出率が 50% を切ったときは、コンタクトシートを開いて目視し、
  隠れているか確認してから報告する（数字だけで完了扱いにしない）

## テロップと併用するとき

**カット＋テロップ（video-editing）を先に済ませ、完成MP4に最後スタンプをかける。**
先にスタンプを乗せるとカットで尺が変わって位置が合わなくなる。

## 設計（触る前に読む）

- 検出は OpenCV YuNet（`assets/face_detection_yunet_2023mar.onnx`）。無ければ Haar に落ちる
- 検出は2フレームおき。間は線形補間し、EMAを往復かけて揺れを取る
- **検出が切れても既定では消えない**（直前の位置を保持し続ける）。
  顔出しNGの人の動画で「1フレームだけ素顔が出る」事故を防ぐための仕様。
  カット割りの多い動画で邪魔なときだけ `--lost-hold` を使う
- `--edge clamp`（既定）で画面外にはみ出さないよう内側へ寄せる
- `--scale` は「**絵の顔**が、検出した顔の何倍か」。絵全体の大きさではない。
  `<スタンプ>.json` が無いときは絵全体を顔とみなすので、従来どおりの挙動になる
- 音声は再エンコードせずそのままコピーされる
