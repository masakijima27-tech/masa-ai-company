# 営業先リストと進め方

## 1. 狙うべきマーケ会社（優先順）

| 優先 | タイプ | 理由 | 刺さるサービス |
|---|---|---|---|
| ★★★ | Web広告運用代行（リスティング・SNS広告） | LP・バナー・広告動画が常に必要 | LP、バナー量産、広告動画、広告レポート自動化 |
| ★★★ | SNS運用代行 | ショート動画の量産が追いつかない | ショート動画、投稿画像、自動投稿ツール |
| ★★★ | 小規模の広告代理店（〜30名） | 制作部門がなく外注頼み | 全般（OEMが刺さりやすい） |
| ★★ | SEO・コンテンツマーケ会社 | 記事・サイト制作の外注先が必要 | SEO記事、サイト制作、アフィリ |
| ★★ | MEO・店舗集客コンサル | 店舗HP・LINE・予約が欲しい客が多い | HP、LINEミニアプリ、予約システム |
| ★★ | EC支援・コンサル | 構築と運用が手一杯 | Shopify構築、商品ページ量産、3D商品画像 |
| ★★ | 経営コンサル・DX支援 | 「AIで業務改善」の相談が多い | 業務自動化、AIチャットボット、研修 |
| ★ | Web制作会社 | 繁忙期の外注、苦手分野（動画・3D・アプリ）の補完 | 動画、3DCG、アプリ |
| ★ | 士業・フランチャイズ本部 | 顧問先・加盟店を大量に抱えている | HP、業務自動化（紹介プラン） |

## 2. 見つけ方
- Google検索：「広告運用代行 {地域}」「SNS運用代行」「Instagram運用 代行」
- 発注・受注サイト：比較ビズ、アイミツ、PRONIなどに掲載している会社
- X / Instagram：「SNS運用代行」「マーケター」でプロフィール検索
- 交流会・セミナー：マーケ系勉強会、商工会議所、BNIなど
- 既存の知り合い・取引先からの紹介（**一番成約率が高い**）

## 3. リストの項目（スプレッドシート）
| 会社名 | URL | タイプ | 従業員数 | 担当者 | 連絡手段 | 初回連絡日 | 返信 | 面談日 | 契約プラン | 案件数 | 備考 |

## 4. KPI（目安）
| 項目 | 月の目標 | 想定の割合 |
|---|---|---|
| 連絡数 | 100社 | — |
| 返信 | 10社 | 返信率10% |
| 面談 | 5社 | 面談率50% |
| パートナー契約 | 2社 | 契約率40% |
| 案件化（3ヶ月以内） | 1社あたり月0.5〜1件 | — |

→ 半年で **パートナー10社 × 月0.5件 = 月5件** の案件が流れる状態を目標にする。

## 5. 90日計画
### 1〜30日：準備と初動
- [ ] サービスメニューの価格を確定（`01`）
- [ ] 報酬率と契約書のひな形を確定（`03`）
- [ ] 実績事例を3つ用意（自社制作のサンプルでも可）
- [ ] 営業先リスト200社作成
- [ ] 100社に初回連絡

### 31〜60日：面談と契約
- [ ] 面談5〜10社
- [ ] パートナー契約2〜4社
- [ ] 最初の案件で商談同席 → 成功事例を作る
- [ ] 反応がよかったタイプに絞って追加で100社連絡

### 61〜90日：仕組み化
- [ ] パートナー向けの月1回の情報共有（新サービス・事例）
- [ ] 成果の出たパートナーの事例を他のパートナーに共有
- [ ] 問い合わせ〜見積の自動化（フォーム → 見積テンプレ）
- [ ] 営業リスト作成・メール送信自体をAIで自動化

## 6. パートナーを動かすコツ
- **最初の1件を全力で成功させる**（同席・スピード対応）
- 「何を売ればいいか」が分かるよう、**セット商品と取り分を1枚** で渡す
- 報酬の支払いは **早く・正確に**（信頼の土台）
- 月1回、「こんな案件ありました」と事例を送って思い出してもらう
