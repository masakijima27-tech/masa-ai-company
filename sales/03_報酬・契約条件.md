# 報酬・契約条件

> 数字はすべて目安です。粗利を見て最終決定してください。【要調整】

## 1. 3つのプラン

### ① 紹介パートナー
- やること：お客様をつなぐだけ（商談・見積・制作は当社）
- 報酬：**初回契約額の15%**
- 継続契約：**月額の10%を12ヶ月間**
- 向き：お試し、営業が得意でない会社、フリーランス

### ② 取次（代理販売）パートナー
- やること：提案・見積の提示・お客様との窓口
- 報酬：**契約額の25%**
- 継続契約：**月額の20%を契約が続く限り**
- 当社サポート：資料提供、技術的な質問への回答、商談同席（初回〜3件まで）
- 向き：営業力のあるマーケ会社・広告代理店

### ③ OEM（ホワイトラベル）パートナー
- やること：御社の商品として販売、窓口・請求すべて御社
- 仕組み：**定価の60〜70%** でパートナーに卸し、販売価格は自由
- 当社は表に出ない（御社名義での納品、秘密保持）
- 向き：自社サービス化したい会社、制作部門を持ちたい会社

## 3. 支払い
- 当社がお客様から入金を確認した月の **月末締め・翌月末払い**
- 分割入金の場合は入金額に応じて按分
- 振込手数料は当社負担

## 4. 契約書に入れること（チェックリスト）
- [ ] 報酬率・対象となる売上の定義（税別・実費除く など）
- [ ] 報酬の対象期間（継続報酬は何ヶ月か）
- [ ] 「紹介」と認める条件（紹介フォームの記録日から6ヶ月以内の成約 など）
- [ ] 顧客の重複時のルール（先に登録した方を優先）
- [ ] 秘密保持（NDA）
- [ ] 顧客の直接引き抜き禁止（双方）
- [ ] 価格の決定権（取次は当社定価、OEMは自由）
- [ ] 品質・クレーム対応の窓口と責任範囲
- [ ] 返金・キャンセル時の報酬の扱い
- [ ] インボイス対応（適格請求書の発行）
- [ ] 契約期間と解約（1年自動更新、1ヶ月前通知 など）
- [ ] 反社会的勢力の排除

> 契約書の最終版は弁護士・専門家に確認してもらってください。

## 5. やってはいけないこと（トラブル防止）
- 報酬を口約束で決める → 必ず書面
- 「何でも・いくらでも安く」と言わせる → 最低価格をパートナーに共有
- 納期をパートナーが勝手に約束 → 納期は必ず当社確認後に回答
