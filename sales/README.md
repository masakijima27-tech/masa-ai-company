# 営業外注キット（マーケティング会社向けパートナー営業）

MASA AIチームのサービスを、マーケティング会社に「売ってもらう」ための資料一式です。

| ファイル | 用途 |
|---|---|
| [01_サービスメニュー.md](01_サービスメニュー.md) | 対応できる全サービスの詳細と価格目安（パートナーに渡す商品カタログ） |
| [02_パートナー提案書.md](02_パートナー提案書.md) | マーケ会社に「一緒に売りませんか」と提案する資料 |
| [03_報酬・契約条件.md](03_報酬・契約条件.md) | 紹介・取次・OEMの3プランと報酬率、契約で決めること |
| [04_アプローチ文面テンプレ.md](04_アプローチ文面テンプレ.md) | 初回メール／DM／フォーム営業／フォローの文面 |
| [05_営業先リストと進め方.md](05_営業先リストと進め方.md) | 狙うべきマーケ会社の条件、リスト作り、KPI、90日計画 |
| [06_パートナー向けトーク・FAQ.md](06_パートナー向けトーク・FAQ.md) | パートナーがお客様に話すトークと想定質問 |
| [07_営業案件リスト.md](07_営業案件リスト.md) | **全78案件**の一般相場・AI会社相場・当社価格・作業範囲・営業報酬（営業に配る本体） |
| [08_価格戦略・営業報酬・営業パターン.md](08_価格戦略・営業報酬・営業パターン.md) | 勝てる価格帯、営業報酬の決め方、素人SNS〜営業代行まで7つの営業パターン |
| [09_営業フロー（アポ→クローザー→エンジニア→成約）.md](09_営業フロー（アポ→クローザー→エンジニア→成約）.md) | ファーストアプローチ台本（業種別）、トスアップシート、ヒアリング、エンジニア確認、クロージング |
| `tools/` | `case_data.py` を直して `python3 sales/tools/build_cases.py` で07と共有ページを再生成 |

## 使い方（最短ルート）

1. `01` の価格を自社の実際の単価に直す（`【要調整】` の箇所）
2. `03` の報酬率を決める
3. `05` の条件でマーケ会社を50社リスト化
4. `04` の文面で連絡 → 面談で `02` を見せる
5. 契約後、`01` と `06` をパートナーに渡す
